SkyTech — Responsive Technology Landing Page

SkyTech is a responsive technology landing page built with HTML and CSS. It was created as my first portfolio project while learning frontend web development.

The project demonstrates my understanding of webpage structure, styling, layouts, and responsive design.

Live Demo

"Visit SkyTech" (https://david-760.github.io/SkyTech-/)

Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- Features section with responsive cards
- About section with an image
- Customer testimonials section
- Contact form interface
- Responsive footer with quick links
- Hover effects and CSS transitions
- Mobile portrait and landscape layouts

Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Transitions

What I Learned

While building SkyTech, I practised:

- Structuring webpages with semantic HTML.
- Styling elements with CSS.
- Creating layouts with Flexbox and CSS Grid.
- Building responsive designs for different screen sizes.
- Using media queries for mobile and landscape layouts.
- Applying hover effects and transitions.
- Organising project files and publishing websites with GitHub Pages.
